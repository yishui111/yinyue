# 3-so-vits-svc · 唱歌换声（核心引擎）

把歌曲里的原唱**换成二次元音色，旋律保持不变**。这是整个需求的核心引擎。

## 怎么用

| 想干嘛 | 双击 |
|---|---|
| 开换声服务 | `启动.bat` → http://127.0.0.1:6843 |
| 停掉 | `停止.bat` |
| 跑一遍自测 | `运行测试.bat`（服务没开会自动拉起） |

服务开着时，浏览器访问 **http://127.0.0.1:6843** 就是网页控制台（`web\index.html`，
由服务自己提供，不用另起前端）。页面三个功能区和服务接口一一对应：

| 页面区域 | 对应接口 | 干什么 |
|---|---|---|
| 服务状态 | `GET /health` | 服务是否在线、CUDA/GPU 信息 |
| 角色模型 | `GET /models` | models\ 下的角色清单，点卡片选中 |
| 唱歌换声 | `POST /svc/change_voice` | 上传干声、调参数、试听下载结果 |

注意：G: 是外接机械盘时，**服务冷启动导入 torch 可能要几分钟**（黑窗口没打印
"Running on" 之前页面会显示"服务未响应"，属正常，等即可）；缓存热了之后就快。

自测做的事：拉起服务 → 列出可用角色 → 拿 `tests\testdata\test_input.wav`
换成一个角色（默认 furina）的音色 → 写到 `输出\` 下。

换角色：`runtime\py312\python.exe tests\test_svc.py nahida41`

## 现成的角色

`models\` 下 6 个：**furina**（芙宁娜）、**nahida41**（纳西妲）、**hutao**（胡桃）、
**klee**（可莉）、**randenEi**（雷电将军）、**yaoyao**（瑶瑶）

想加新角色：往 `models\` 里放 `角色.json` + `角色_G.pth`，
有聚类/特征检索就再放 `角色_kmeans.pt` 或 `角色_feature_and_index.pkl`，
服务启动时自动扫描，不用改代码。

## 接口

```
GET  /                        网页控制台（web/index.html）
GET  /health                 健康检查（含显卡信息）
GET  /models                 可用角色列表
POST /svc/change_voice       换声
     audio          form-data 上传干声 wav
     model          角色名，如 furina
     transpose      变调半音数，默认 0
     auto_f0        1=自动预测音高（唱歌推荐），0=跟原曲音高
     cluster_ratio  聚类/特征检索比例 0~1，默认 0（1=最像角色本人）
     f0_predictor   rmvpe / crepe / pm，默认 rmvpe
     speaker        说话人（可选，默认模型第一个）
```

## 目录说明

```
3-so-vits-svc\
├─ 启动.bat / 停止.bat / 运行测试.bat / 安装环境.bat
├─ web\index.html    网页控制台（服务 GET / 直接返回，与接口一一对应）
├─ tests\            自测脚本 + 测试音频
├─ 输出\             自测产物
├─ runtime\py312\    自带解释器的 Python 环境
├─ models\           角色模型（json + pth + 聚类/索引）
├─ pretrain\         预训练件（contentvec onnx、nsf_hifigan、rmvpe）

└─ requirements-infer.txt   推理最小依赖清单
```

## 注意

- 角色模型用的是 `vec768l12-onnx` 编码器，所以**推理不需要 fairseq**
  （官方依赖里最难装的包）。要训练新角色才需要按官方 requirements 另装
- 官方 `numpy==1.23.5` / `scipy==1.10.0` 没有 py3.12 的轮子，
  `requirements-infer.txt` 已放宽到 `numpy<2` + 新 scipy
- `cluster\__init__.py` 的 `torch.load` 加了 `weights_only=False`
  （torch 2.6+ 默认改了，kmeans 聚类文件必须关掉安全加载）
- onnxruntime-gpu 1.17.1 要 cuDNN 8，`svc_service.py` 启动时会把
  `torch\lib` 和 `nvidia\*\bin` 挂进 DLL 搜索路径
- 一次只留一个角色模型在显存里，换角色会自动释放上一个
