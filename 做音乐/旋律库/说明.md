# 旋律库说明

每首旋律就是一个 `.abc` 文件(YuE2 原生方言,须通过官方 abc_tools 校验)。
「旋律来源」下拉框与曲谱工坊都会读取本文件夹。**往这里放文件 = 扩充曲库,不需要任何训练。**

## 当前曲库构成

### 自写示例(4 首,带和弦,生成时 cot=full)

| 文件 | 风格 |
|---|---|
| 月下小径-小调抒情 | A 小调,4/4,76 BPM |
| 星星摇篮曲-68拍温柔 | G 大调,6/8,60 BPM |
| 快乐小狗-欢快舞曲 | D 大调,4/4,120 BPM |
| 水墨江南-中国风 | C 宫五声,4/4,80 BPM |

### TheSession 传统曲(4 首,无和弦,生成时自动用 cot=melody)

来自 thesession.org 社区数据(爱尔兰传统曲目,旋律为公有领域,社区转谱),
由 `工具\曲谱转换入库.py` 自动转换并校验入库。

## 三种扩充方式

1. **曲谱工坊(页面 🎼 区块)**:描述风格 → DeepSeek 原创 → 自动校验入库;
2. **手写/改写**:参照《约束文档》第三章的方言规范写 `.abc` 放进来
   (注意:`T:` 行留空,每 1~4 小节一组交替 Vocal/Ins,单小节拍数必须精确);
3. **批量转换**:`python 工具\曲谱转换入库.py --count N`(数据缓存于 `工具\缓存\`,
   `--refresh` 可更新;随机种子固定,多跑几次会换到不同批次)。
