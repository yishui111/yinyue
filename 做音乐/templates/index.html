做音乐 故事 → DeepSeek 出词曲 → 本地 YuE2 唱出来

四步流程见下:下载约束词发给 DeepSeek → 讲故事 → 粘贴词曲 → 一键合成开唱。

使用流程(完整闭环)

三份给 DeepSeek 的约束词文档: ⬇ 作曲约束词 ⬇ 旋律提取约束词 ⬇ 按旋律填词约束词
  1. 写词作曲(两种方式任选)
    配了 API 密钥:在 ⓪ 输入故事自动生成。手动:下载「作曲约束词」+ 故事发给 DeepSeek, 把输出的 json/abc 粘贴到 ① 表单。
  2. 想仿照某首歌?先把旋律"提"进曲库
    下载「旋律提取约束词」,连同一首歌的信息(歌名/简谱/乐谱文本)发给 DeepSeek, 把输出的 abc 用 ⓪ 区块的「从文件入库」上传;或在 🎼 曲谱工坊让 DeepSeek 原创新旋律。
  3. 选旋律,按旋律写词
    ⓪ 的「旋律来源」下拉框选中曲库里的旋律,输入故事点生成 —— DeepSeek 只按这条旋律填词。 手动路线:下载「按旋律填词约束词」,连同该曲谱内容 + 故事发给 DeepSeek,把输出的 json 粘贴到 ①。
  4. 合成,开唱
    填歌名点「▶ 开始合成」,约一分钟;唱完在「我的作品」在线试听。

⓪ 从故事直接生成词曲(推荐,需 DeepSeek API 密钥)

生成约需 1~2 分钟,完成后自动填入下面 ① 的表单

🎼 曲谱工坊(生成新旋律入库)

生成后自动通过官方校验器检查并放入旋律库,「旋律来源」下拉框立即可选。
