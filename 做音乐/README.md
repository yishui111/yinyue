# 做音乐 · 项目入口

**给一个故事,唱出一整首歌。** 工作流:故事 → DeepSeek 出歌词和旋律曲谱 → 本地 YuE2-3B 照谱演唱
(人声+伴奏,48kHz 立体声,约 1 分钟出一分钟的歌)。 melody 可自选曲库旋律、可让 AI 原创入库,
也可按《旋律提取约束词》仿照任意歌曲。全部本地运行,无需联网(仅 DeepSeek 写词作曲需要网络)。

## 三秒上手

1. 双击 **`启动.bat`** → 自动打开页面 `http://127.0.0.1:7866`;
2. 页面上填一次 DeepSeek API 密钥(存本机 `config.json`);
3. 输入故事 → 「✨ 生成歌词和曲谱」→ 「▶ 开始合成」→ 「我的作品」试听;
4. 不用了双击 **`停止.bat`**(唯一关闭方式)。

## 文件夹地图

| 位置 | 内容 |
|---|---|
| `启动.bat` `停止.bat` `自检.bat` `唱歌.bat` | 四个入口:启网页 / 关服务 / 体检 / 免网页直接唱 |
| `server.py` `sing.py` `templates\` | 网页服务与合成脚本 |
| `runtime\py312\` | 便携 Python 环境(torch CUDA、flask、yue2,约 7GB) |
| `weights\` | 模型权重 YuE2-3B + VAE(约 7.3GB) |
| `旋律库\` | 旋律曲库(.abc)。扩充方式见 `旋律库\说明.md` |
| `作品\` | 你唱过的歌(成品 + 曲谱 + 日志) |
| `测试\` | 验收案例与《测试报告.md》 |
| `工具\` | 曲谱批量转换入库等脚本 |
| `YuE\` | 上游 YuE2 官方仓库(校验工具/文档/示例) |
| `文档\` | 使用说明 / 原理说明 / 三份 DeepSeek 约束词 / 模型调研 |
| `config.json` | 你的 DeepSeek API 密钥(已 gitignore,勿外传) |

三份约束词文档在页面上也有下载按钮:作曲约束词(写词+作曲)、旋律提取约束词(把一首歌变成曲谱)、
按旋律填词约束词(选定旋律后按故事写词)。

## 复制到别的电脑

1. **整个 `做音乐\` 文件夹原样复制**(含 `runtime\` 与 `weights\`,共约 15GB);U 盘/移动硬盘直拷即可;
2. 目标电脑要求:**NVIDIA 显卡(8GB 显存以上最佳)+ 装好显卡驱动**,不需要装 Python 或任何依赖;
3. 双击 `启动.bat` 即用。首次启动 Windows Defender 会扫描大量文件,加载偏慢属正常;
4. 提速(可选):把 `runtime\py312` 和 `weights` 复制到目标机的**内置 SSD**(例如 `D:\yue2`),
   程序会自动优先使用 `D:\yue2` 的环境和权重(本机现状即如此);也可用环境变量 `YUE2_HOME`
   指向权重目录、`YUE2_PYTHON` 指向 Python 解释器。

## 出问题了

- 页面打不开:双击 `自检.bat`(8 项 OK 才算环境正常);
- 合成失败:看 `作品\歌名\合成日志.txt` 最后几行;
- 服务异常:`服务日志.txt` / `服务崩溃.txt`;
- 更多:《文档\使用说明.md》(日常)、《文档\原理说明.md》(旋律从哪来/怎么仿照)。
