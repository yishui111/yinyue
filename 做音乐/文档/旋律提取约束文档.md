# 旋律提取约束文档(把一首歌变成曲库曲谱)

> 用途:把本文档整篇发给 DeepSeek,再附上"一首歌"的信息,DeepSeek 就会输出一份
> 可直接放入 `做音乐\旋律库\` 的 `.abc` 曲谱(与曲库内其他曲谱同规格)。
> 之后在合成页面的「旋律来源」下拉框选中它,再按《按旋律填词约束词》填词,即可唱出新歌。

## 一、重要前提(必须先读)

你(DeepSeek)**听不到音频文件**。用户能给你的"歌"只有三种形态,处理方式不同:

| 用户给的形态 | 你能做什么 | 效果 |
|---|---|---|
| 简谱 / 五线谱文本 / 已有 ABC | 按下述规范**精确转换** | ✅ 最佳,推荐 |
| 广为流传的歌曲的**歌名**(如《茉莉花》《欢乐颂》) | 凭记忆写出**近似旋律** | ⚠️ 音高节奏可能有出入,属再创作 |
| 音频文件(mp3/wav) | **无法处理**,请让用户提供简谱或描述 | ❌ |

音频转谱需要本地工具(项目原理文档路线 B:SheetSage2),不属于本文档范围。
若凭记忆写著名歌曲,请在输出末尾的 % 注释里标注"近似旋律,非原谱"。

## 二、输出格式(严格,不要输出任何其他文字)

第一行:文件名建议(格式 `文件名:中文名`,将作为曲库文件名)。
之后:一个 ```abc 代码块,内容遵守第三节全部规范。

```text
文件名:茉莉花
```abc
X:1
T:
...(曲谱正文,规范见下)
```
```

## 三、ABC 方言规范(逐条硬性约束,与曲库完全一致)

### 3.1 文件头(固定写法)

```abc
X:1
T:
M:4/4
L:1/16
Q:1/4=88
V: Vocal clef=treble name="Vocal Melody" snm="Vocal"
V: Ins clef=treble name="Ins Melody" snm="Inst."
K:C
```

- `T:` 行**必须留空**(文件名放在"文件名:"一行)。
- `M:` 拍号:4/4、3/4、6/8、2/4 均可;`L:1/16` 时每小节容量:4/4=16 单位、3/4=12、6/8=12、2/4=8。
- `Q:1/4=数字` 四分音符 BPM(60~130,按曲子风格定)。
- 两行 `V:` 声部声明必须有;`K:` 用标准大小调(C/G/D/A/E/F 或 Am/Em/Bm/Dm 等)。

### 3.2 正文结构(关键!)

- **每 1~4 小节为一组**,先 `V: Vocal` 行再 `V: Ins` 行交替出现;一组内小节数不能超过 4。
- Vocal 行:旋律 + 引号和弦(可选);Ins 行:休止 `Z`(一组 4 小节写 `Z4|`,1 小节写 `Z|`)。
- 用 `% 注释` 划分段落,如 `% verse`、`% chorus`、`% bridge`,方便以后按段落填词。
- 总长 8~40 小节,取歌曲的主歌+副歌部分即可,不必写全曲。

### 3.3 音符写法(L:1/16 时)

| 写法 | 含义 |
|---|---|
| `C` `D` … `B` | C4~B4(中音区) |
| `c` `d` … `b` | C5~B5 |
| `C,` / `c'` | C3 / C6 |
| `C2` | 十六分音符(2 单位);`C4` 八分;`C8` 四分;`C16` 二分;`C32` 全音符 |
| `z4` `z8` | 休止;`Z4` = 整休 4 小节 |
| `G8-G8` | 连音线(同音高才可连) |
| `^F` `_B` `=F` | 升/降/还原 |

- 每小节单位数必须**精确**等于拍号容量,写完逐小节核对。
- 时值乘数只允许 1,2,3,4,6,8,12,16,24,32,48;其他时值用连音线拼接。
- **人声音域 C4~G5**:主体在 C~c 之间,高潮短暂到 d/e;超出就移八度。
- 一字一音为主,长音放在开口韵母的字上(转换简谱时:一个简谱音符 ≈ 2 单位起)。

### 3.4 和弦(可选,写在 Vocal 行内引号里)

允许:`C` `G` `Am` `F` `Dm` `Em` 及 `m m7 7 maj7 dim aug sus4 sus2 6 m6 dim7 m7b5 7sus4 m(maj7)` 后缀与 `/低音` 转位。
禁止:`maj9` `13` `alt` `add`、数字级数、自造记号。每小节 1~2 个;长音跨和弦必须用连音线切开。
**不确定和声时可以一个和弦都不写**——曲库会自动按"无和弦"处理(伴奏自由发挥)。

### 3.5 禁止清单(出现即作废)

```
三连音(3: )、装饰音(~ . )、滑音、圆滑线、多声部叠音 [CE]、
反复记号 |: :|、一二房子 [1 [2]、w: 歌词行、自定义声部、 Tuplet、非常规调式
```

(反复的段落直接把那几小节**再写一遍**即可。)

### 3.6 输出前自检清单

1. `T:` 是否留空;
2. 每 1~4 小节一组、Vocal/Ins 交替、每小节拍数正确;
3. 音域 C4~G5;未用任何禁止记号;结尾无悬空连音线;
4. 和弦都在允许表内(或干脆没有和弦);
5. 第一行写了 `文件名:xxx`。

---

## 四、产出后怎么用

把 ```abc 代码块内容保存为 `文件名.abc`(UTF-8),放入 `做音乐\旋律库\` 文件夹;
或在做音乐页面「🎼 曲谱工坊」区块用「从文件入库」按钮直接上传(会自动校验)。
之后在「旋律来源」下拉框就能选到它。
