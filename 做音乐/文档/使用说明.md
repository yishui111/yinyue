# 做音乐 · 使用说明

> 流程:故事 → DeepSeek 出歌词和曲谱 → 本地 YuE2 唱出来。
> 形态与你的其他引擎一致:**双击 `启动.bat` → 自动打开网页 → 页面上操作;不用了双击 `停止.bat`**。
> 唱歌模型:YuE2-3B(multimodal-art-projection/YuE,yue2-infer 0.1.6)。
> 实测(RTX 4080 16GB):加载 5~6 秒,显存峰值约 8GB,1 分钟歌曲约 1 分钟合成,输出 48kHz 立体声成品。

## 三个脚本

| 脚本 | 作用 |
|---|---|
| **`启动.bat`** | 拉起本地网页服务(端口 7866)并自动打开浏览器 `http://127.0.0.1:7866`。服务**无窗口后台运行**,任务栏不会有黑框,不存在"误关窗口" |
| **`停止.bat`** | 一键关闭网页服务与正在合成的任务(唯一的停止方式) |
| `自检.bat` | 检查显卡/依赖/权重是否就绪,不占 GPU。出问题时先跑它 |

> 服务运行痕迹:项目根目录的 `服务日志.txt`(访问与启动记录)、`服务崩溃.txt`(只在异常时出现)。
> 每次合成的完整日志在 `作品\歌名\合成日志.txt`。

> 另有 `唱歌.bat`(把作品文件夹拖上去直接唱)是不开网页的备用入口,效果完全一样。

## 网页上怎么用

页面顶部就写着完整流程(共 4 步)。**推荐用 ⓪ 区块全自动**,全程不离开页面:

1. **填一次 DeepSeek API 密钥**(⓪ 区块,保存到本机 `config.json`,仅在调用 DeepSeek 官方接口时使用);
2. **输入故事**,点「✨ 生成歌词和曲谱」——约 1~2 分钟,词曲自动填入下方表单;
3. 满意就点 **「▶ 开始合成」**;想改旋律直接编辑曲谱框里的 abc 再合成;
4. 唱完在「我的作品」**在线试听**。

不想配密钥也可走手动路线:点「⬇ 下载约束词」(即《约束文档-故事转歌词与旋律.md》)发给
DeepSeek 网页版,把它输出的两段代码粘贴到 ① 表单,效果相同。

页面五个区块:

0. **⓪ 从故事直接生成词曲**:API 密钥 + 故事 → 自动填好 ① 的表单。
   **「旋律来源」下拉框**选「自动」= DeepSeek 写词+作曲;选某首曲库旋律 = DeepSeek 只按
   该旋律的音符数填词,歌就严格走那条旋律。
0b. **🎼 曲谱工坊**:描述想要的旋律(如"小调、忧伤、3/4 拍")→ DeepSeek 原创 →
   官方校验通过后自动入库并选中。想让曲库更丰富就在这里"训练"新旋律。
1. **① 合成一首歌**:
   - 把 DeepSeek 按《约束文档》输出的 ```json 内容粘贴进「歌词 song.json」;
   - 把 ```abc 内容粘贴进「曲谱 score.abc」(**可留空** = 只写词,旋律让模型自己作);
   - 填歌名 → 点「▶ 开始合成」→ 下方实时滚动进度 → 完成自动停。
   - 不想自己找词曲,点「载入示例」可直接试跑全流程。
2. **② 我的作品**:所有唱过的歌都在这里,直接在线试听(`audio.flac` 文件在 `作品\歌名\` 里,
   连同模型采用的 `score.abc` 和 `合成日志.txt`)。对旋律不满意:改那个 abc 文件,回到①重新合成同名歌曲即可。
3. **③ 环境自检**:一键在页面里跑自检。

## 目录与位置

|---|---|
| `G:\xmgousi\音乐模型\做音乐\` | 本项目:启动/停止/页面(`server.py` + `templates\`)、约束文档、`作品\`、`测试\` |

| `D:\yue2\weights\` | 模型权重(YuE2-3B 6.8GB + VAE 0.5GB) |

> 权重和环境放 D 盘固态,是因为 G 盘是 USB 机械盘,加载 7GB 权重太慢。
> 挪位置的话:改 `sing.py` 里的 `YUE2_HOME`、两个 bat 和 `server.py` 里的 python 路径。

## 已处理的坑(留档)

- **bat 内容必须纯 ASCII**:cmd 用 GBK 解析 bat,UTF-8 中文会拆成乱码字节搅乱命令
  (最早报 `'?chcp' 不是内部或外部命令` 就是这个)。四个 bat 均已纯英文化。
- Windows 版 torch 无 flash-attention 内核,官方 auto 探测误判报错
  `USE_FLASH_ATTENTION was not enabled for build` —— `sing.py` 已打补丁强制 cudnn/sdpa。
- 网页合成偶发一次无报错子进程退出(重跑即好)—— 每个任务的日志现已落盘到
  `作品\歌名\合成日志.txt`,并开启 faulthandler,再遇到可直接看文件定位。
- G 盘为 USB 机械盘,大文件慢 —— 权重与环境在 D 盘固态。
