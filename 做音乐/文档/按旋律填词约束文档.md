# 按旋律填词约束文档(曲库选曲 + 故事 → 歌词)

> 用途:你在做音乐页面「旋律来源」下拉框选中了一条旋律后,把本文档整篇、**那条旋律的
> .abc 文件内容**、以及**你的故事**一起发给 DeepSeek,它就只输出歌词(json),
> 拿回页面粘进「歌词 song.json」框,点合成即可——歌会严格走你选的旋律。
> (页面上配了 API 密钥的话,这一步是自动的;本文档供手动路线使用。)

## 一、你(DeepSeek)的任务

用户会给你三样东西:
1. 本文档;
2. 一段 ```abc 代码块(已经写好的旋律曲谱,来自曲库);
3. 一个故事。

你要做的是**为这条旋律填词**:只输出一个 ```json 代码块,不要输出 ```abc,不要输出任何解释文字。
旋律一个音都不能改——作曲不是你的任务,填词才是。

## 二、json 格式(与曲库生成规则一致)

```json
{
  "id": "yingtao_xiaowan",
  "style": "Mandarin, gentle music box lullaby, soft airy female vocal, celesta, tender and sleepy, 60 BPM",
  "lyrics": "[Verse]\n第一行\n第二行\n第三行\n第四行\n\n[Chorus]\n第一行\n第二行\n第三行\n第四行",
  "cot": "melody",
  "seed": 42
}
```

| 字段 | 要求 |
|---|---|
| `id` | 短英文小写标识,与旋律/故事相关 |
| `style` | **必须以 `Mandarin` 开头**,之后英文写曲风/人声/乐器/情绪;**结尾 BPM 必须等于旋律里 `Q:1/4=数字` 的那个数字** |
| `lyrics` | 段落标签 `[Verse]` `[Chorus]` `[Bridge]` 等,段落间空行;**段落必须对应旋律里的 `% 注释段落`**;每行汉字数 ≈ 该行旋律的音符数(中文一字对一音,允许 ±1);长音放在开口韵母的字上 |
| `cot` | **看旋律定**:旋律里有引号和弦(如 `"G"` `"Am7"`)→ 填 `"full"`;旋律里没有和弦 → 填 `"melody"` |
| `seed` | 任意整数 |

## 三、填词要领

1. 先数旋律:每个 `% 段落` 有几小节、每小节几个音符(数 Vocal 行里的音名字母,连音线 `8-8` 算一个音);
2. 歌词讲故事:保留故事的核心人物/情节/意象,按段落推进(主歌铺陈、副歌点题);
3. 字数对齐:第 n 行歌词的字数 = 第 n 个乐句的音符数(允许 ±1,模型会自行微调);
4. 音域与唱感:避开生僻字;副歌放情感最重的句子;
5. 不需要你输出旋律,不需要输出解释,只输出上面那一个 ```json 代码块。

## 四、产出后怎么用

把 json 代码块内容保存/粘贴到做音乐页面「歌词 song.json」框;
「曲谱 score.abc」框填入用户选中的那条旋律内容(页面上选中旋律后它已自动带出);
填歌名 → 点「▶ 开始合成」,约一分钟,唱完在「我的作品」试听。
