# 4-e2e · 端到端：音乐视频 → 二次元音色

完整跑一遍：**视频 → 提音轨 → 人声伴奏分离 → 人声换二次元音色 → 混音 → 封装回视频**。
视频画面原样保留，只换人声的音色。

## 怎么用

**前置：`3-so-vits-svc` 的换声服务必须在跑**（去那个目录双击 `启动.bat`）。
本目录只负责人声分离 + 编排，换声是走 6843 的 HTTP 接口。

然后双击 `运行测试.bat`。默认用 `testdata\输入.mp4` + furina 角色。

命令行用法：

```bash
runtime\py312\python.exe e2e_test.py [输入mp4] [角色名]
runtime\py312\python.exe e2e_test.py testdata\输入.mp4 nahida41
```

产出：
- 成品视频 `输出\输出_<角色>.mp4`
- 中间产物 `输出\中间产物\`（音轨、干声、伴奏、换声后的人声、混音）

## 耗时参考（RTX 4080）

实测（2026-09-15，RTX 4080 空载，32 秒视频，**全程 36 秒**）：

| 步骤 | 耗时 |
|---|---|
| ffmpeg 提音轨 | 2s |
| 人声分离（含加载 bs_roformer） | 2.8s |
| so-vits 换声 | 15s |
| 混音 + 封装回视频 | 3s |

换第二个角色时分离会命中缓存，更快。（早前记录的「分离 316 秒」是当晚磁盘被别的
下载任务打满时的异常值，不是常态。）

## 目录说明

```
4-e2e\
├─ 运行测试.bat / 安装环境.bat
├─ e2e_test.py        端到端脚本
├─ testdata\          输入视频
├─ 输出\              成品视频 + 中间产物
├─ models\pymss\      人声分离模型（bs_roformer_voc_hyperacev2）
└─ runtime\
   ├─ py312\          自带解释器的 Python 环境
   └─ ffmpeg\         自带的 ffmpeg / ffprobe，不依赖系统
```

## 关于 runtime\py312（重要）

这一份是用**硬链接**从 `1-rvc\runtime\py312` 克隆来的 —— 因为人声分离库 `pymss`
只在 1-rvc 的环境里装了（连带 torch 2.7.1+cu118）。

- 看起来是一份完整独立的环境，脚本也照独立环境去用，**行为上没有区别**
- 但**不额外占磁盘**：和 1-rvc 那份共用同一批文件
- 把 `4-e2e` 整个拷到别的机器时，拷出来的就是实打实的完整文件，照样能用
- 删掉 `1-rvc` 也不会影响 `4-e2e`（硬链接只要还有一份引用，数据就在）

不想要这份、想省掉目录体积？直接删 `runtime\py312` 就行，
只是这样 `运行测试.bat` 会因为找不到环境而报错 —— 想再要回来就双击
`安装环境.bat`（会用联网方式重装一份真正独立的）。
