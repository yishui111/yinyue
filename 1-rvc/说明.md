# 1-rvc · RVC 换声 / 训练 WebUI

把一段人声**换成别的音色**，时长和语调都不变。也能用来训练新音色。

## 怎么用

| 想干嘛 | 双击 |
|---|---|
| 开网页界面（推理 + 训练） | `启动.bat` → http://127.0.0.1:7865 |
| 停掉 | `停止.bat`，或直接关掉黑窗口 |
| 跑一遍自测 | `运行测试.bat`（不用先开服务，命令行直接换声） |

自测做的事：加载 `Nahida.pth`，把 `tests\testdata\test_input.wav` 换成纳西妲音色，
结果写到 `输出\test_input_Nahida.wav`。跑通说明模型和环境都正常。

换别的音色：`运行测试.bat` 之后在命令行加参数，或者
`runtime\py312\python.exe tests\test_rvc_cli.py Paimon.pth`

## 现成的音色

`assets\weights\` 下的权重（配 `assets\indices\` 里的同名 index 效果更好）：

`Nahida.pth`、`NahidaCN.pth`、`Paimon.pth`、`dabing.pth`、`keai_pitch.pth`、
`liejun.pth`、`songwukong.pth`、`testnv.pth`

## 目录说明

```
1-rvc\
├─ 启动.bat / 停止.bat / 运行测试.bat / 安装环境.bat
├─ tests\               自测脚本 + 测试音频
├─ 输出\                自测产物（换声后的 wav）
├─ runtime\py312\       自带解释器的 Python 环境（拷到哪都能跑）
├─ assets\
│  ├─ weights\          已训练的音色权重
│  ├─ indices\          对应音色检索索引
│  ├─ hubert_base\      基座模型
│  ├─ pretrained_v2\    训练用底模
│  ├─ rmvpe\            音高提取模型
│  └─ pymss_weights\    人声分离（UVR）模型
├─ webui.py             网页界面入口
└─ tools\pymss_webui.py 人声分离界面（pymss）
```

## 注意

- 这个项目的环境里装了 `pymss`（人声分离库），`4-e2e` 的人声分离就是靠它
- 训练很吃显存，训练时别同时开另外两个服务
- `go-webui.bat` / `go-realtime_gui.bat` 是上游自带的脚本，需要 `runtime\python.exe`，
  在本项目用不了，忽略即可
