# 0-web · 总控页：一个页面对应四个项目

浏览器里的统一入口。页面上每个板块与一个服务/目录**一一对应**，
状态灯就是该服务 `/health`（或等价探测）的真实结果：

| 页面板块 | 对应目录 | 服务地址 | 页面功能 | 背后调用的真实接口 |
|---|---|---|---|---|
| 🎤 唱歌换声 | `3-so-vits-svc` | http://127.0.0.1:6843 | 选角色 + 传干声 → 换声试听/下载 | `GET /models`、`POST /svc/change_voice` |
| 🗨️ 文字转语音 | `2-gpt-sovits` | http://127.0.0.1:9880 | 选角色 + 输文本 → 合成试听/下载 | `GET /set_gpt_weights`、`/set_sovits_weights`、`POST /tts` |
| 🎛️ RVC 换声 | `1-rvc` | http://127.0.0.1:7865 | 选音色 + 传干声 → 换声；一键打开完整 WebUI | 1-rvc 同款推理管线（rmvpe + 索引） |
| 🎬 视频换声 | `4-e2e` | 本地流水线 | 选角色（可选传视频）→ 转换进度 → 成品预览/下载 | 运行 `4-e2e\e2e_test.py`（依赖 6843） |

## 怎么用

1. 先把引擎服务拉起来：根目录双击 `全部启动.bat`（或各项目自己的 `启动.bat`）。
2. 本目录双击 `启动.bat`，浏览器开 http://127.0.0.1:8100
3. 页面顶部四个状态灯全绿即可使用；哪个是灰的就去对应目录 `启动.bat`。

命令行用法：`runtime\py312\python.exe web_service.py [-a 127.0.0.1] [-p 8100]`

自测：`运行测试.bat`（三个引擎服务在跑的前提下，逐项验证页面与 4 个项目的接口对应）。

## 目录说明

```
0-web\
├─ 启动.bat / 停止.bat / 运行测试.bat / 安装环境.bat
├─ web_service.py      总控服务（标准库 HTTP 服务 + 反代，不起任何模型）
├─ rvc_convert.py      RVC 换声辅助（子进程跑 1-rvc 同款推理管线）
├─ 克隆运行环境.py      runtime\py312 缺失时从 1-rvc / 4-e2e 硬链接克隆
├─ static\index.html   总控页前端（纯静态，无外部 CDN，离线可用）
├─ tests\selftest.py   自测：验证页面接口与 4 个项目一一对应
├─ 输出\               上传缓存 / e2e 任务日志
└─ runtime\py312\      Python 环境（硬链接克隆，不占磁盘）
```

## 设计要点

- **web_service.py 只用 Python 标准库**：不 pip 装任何东西，任何一份 runtime 都能跑；
  RVC 换声和端到端走子进程，不把大模型加载进本服务。
- **页面与后端同源**（页面由 8100 自己发出），浏览器没有跨域问题；
  上游访问全部 `ProxyHandler({})` 绕开系统代理（`HTTP_PROXY` 会把 127.0.0.1
  也送代理返回 502，历史坑），健康检查必须校验 JSON `status=="ok"`。
- **GPT-SoVITS 会自动切角色权重**：`tts_infer.yaml` 的 custom 段默认是底模，
  合成前按角色调 `/set_gpt_weights` `/set_sovits_weights`（只在角色变化时切，避免重复重载）。
- 端到端任务同时只跑一个，页面 3 秒轮询进度和日志尾部；
  角色参数会先对照 6843 的 `/models` 校验，避免白跑几分钟。
- 上传上限 800MB；成品不复制，下载直接指向 `4-e2e\输出\输出_<角色>.mp4`。
