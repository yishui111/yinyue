# 2-gpt-sovits · 文字转二次元语音

给一段文字 + 一句参考音频 → 用那个音色念出来（零样本克隆，不需要训练）。

## 怎么用

| 想干嘛 | 双击 |
|---|---|
| 开 API 服务 | `启动.bat` → http://127.0.0.1:9880 |
| 开网页界面 | `启动界面.bat` |
| 停掉 | `停止.bat` |
| 跑一遍自测 | `运行测试.bat`（服务没开会自动拉起） |

自测做的事：用 `models\ayaka\ref.wav`（神里绫华的参考音频）念一句中文，
结果写到 `输出\tts_out.wav`。

念别的话：`runtime\py312\python.exe tests\test_tts.py 你想念的文字`

## 现成的参考音色

```
models\ayaka\
├─ ref.wav         参考音频（四五秒就够）
├─ ref_text.txt    参考音频对应的文字（必填，识别错会明显影响效果）
├─ Ayaka-e15.ckpt  SoVITS 权重
└─ Ayaka_e8_s176.pth  GPT 权重
```

想加新角色：在 `models\` 下建个目录，放这四样东西，然后 API 的
`ref_audio_path` 指过去就行。

## 接口

```
GET http://127.0.0.1:9880/tts
    text          要念的文字
    text_lang     文字语言，中文 zh
    ref_audio_path 参考音频（相对本项目目录，如 models/ayaka/ref.wav）
    prompt_text   参考音频的文字
    prompt_lang   参考音频语言
    media_type    wav
```

## 注意

- `transformers` 必须是 **4.49.0**，4.50 以上加载 roberta 会报
  "Unable to load weights"。重装依赖时用 `requirements-local.txt`（已钉版本）
- `starlette` 必须留 **0.x**（现装 0.52.1）。装成 1.x 的话网页界面起不来：
  starlette 1.x 改了 `TemplateResponse` 的调用约定，gradio 4.x 会把 dict 当模板名
  传进去 → `TypeError: unhashable type 'dict'` → gradio 自检失败，报
  "When localhost is not accessible ..."（**这个报错是误导的，跟代理和 localhost 无关**）。
  fastapi 只要求 `starlette>=0.46.0`，所以降级不影响 API。已在
  `requirements-local.txt` 里钉了 `starlette<1.0`
- 日文朗读需要的 `pyopenjtalk` 在 Windows py3.12 上要编译，没装；中文不受影响
- `go-webui.bat` 是上游自带的、需要 `runtime\python.exe`，本项目用不了，忽略即可
