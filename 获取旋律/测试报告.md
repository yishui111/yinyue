## 七、已知限制

1. **首次提取慢**：要下载 Demucs（~80MB）+ Whisper（small ~460MB）模型，慢网络可能 20-60 分钟；进度面板能看到卡在哪一步。可设 `HF_ENDPOINT=https://hf-mirror.com` 走国内镜像。
2. **Whisper 听唱歌不准**：见第四节，换大模型或手改。
3. **内存紧张时任务可能失败**：失败信息会显示在进度日志里，重试即可；关闭其他大型 AI 程序可显著提高成功率。
4. 拖腔（一字多拍）会被记成同音高的连续短音，可在表格手动拉长时值。

## 十三、重构：DeepSeek 直出旋律版（2026-09-28，当前版本）

按用户新流程**整体重构**：不再从音频提取旋律（demucs / faster-whisper / pyin / whisper 流水线全部移除，
相关大模型已从虚拟环境卸载，释放约 2.5GB）。旋律改为由 **DeepSeek 网页对话直接生成 JSON**。

### 新流程

1. 点「旋律生成文档」→ 复制 → 填好开头的【填写区】→ 发给 DeepSeek 网页对话框 → 它回复旋律 JSON；
2. JSON 存进 `melodies/` 文件夹（或页面直接粘贴导入，自动校验/规范化/补简谱）；
3. 选一段旋律 → 点「① 生成填词约束文档」（自动注入旋律+每句字数+你的故事）→ 复制发给 DeepSeek；
4. 把它回复的填词 JSON 粘回 → ④ 应用（逐字校验：每句字数必须等于音符数）；
5. 填音色名 → 「🎤 按旋律唱出来」（逐字 TTS → 变调 → 对齐 → 拼接，自动播放）。
