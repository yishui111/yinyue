# 🎼 旋律工作台（DeepSeek 填词演唱版）

给 DeepSeek 一段约束文档，它直接**生成旋律 JSON**；旋律存进本项目的旋律库后，
在页面上选一段 → 自动生成**填词约束文档** → 你加个新故事再喂给 DeepSeek →
它回你一个可演唱的 JSON → 粘回页面 → **一点运行，用 GPT-SoVITS 的真声按旋律唱出来**。

> 本版本已去掉音频分析（不再从音乐文件提旋律，也就不再需要 demucs/whisper 等大模型）。
> 旋律的来源是 DeepSeek——它"听过"海量歌曲，报上歌名可以近似还原主旋律，也可以让它原创。

## 一、快速上手

```
1. 双击 setup.bat        （仅第一次，安装依赖）
2. 把 config.json 里的 gptsovits_voice 改成你的音色名（如 myvoice_test）
3. 双击 启动工作台.bat    （浏览器自动打开 http://127.0.0.1:17865）
```

## 二、完整流程（对应页面左侧 1-2-3）

### ① 旋律从哪来

- 页面点 **「📖 旋律生成文档（给 DeepSeek）」** → 复制全文；
- 修改文档开头的【填写区】：参考歌曲（报真实歌名，DeepSeek 会凭记忆近似还原主旋律；
  写"原创"则让它作曲）、风格、句数、每句长度、调性、BPM；
- 粘贴到 **DeepSeek 网页对话框** 发送 → 它回复一个旋律 JSON；
- 把回复粘到页面 **「➕ 导入旋律」**（或存成 .json 文件放进项目 `melodies/` 文件夹 → 点刷新）。

内置两段示例旋律可直接体验：**示例-小星星**（已填词，选完即可演唱）、**示例-原创抒情**（无词，用于体验填词流程）。

### ② 填新词

- 选好旋律后，点 **「① 生成填词约束文档」**——工作台会把这段旋律的每个音符、
  每句需要几个字、逐字对位/声调/押韵的全部约束自动写好；
- 在文档的【新歌要讲的故事】处写下你的故事（页面上的故事框会自动注入）；
- 复制全文 → 发给 DeepSeek → 它回复填好字的 JSON；
- 粘到页面 **「③ 应用填词」**——系统逐字校验（每句字数必须与音符数一致），
  通过后写入旋律；旋律一个音都不会动。
- 也可以在右侧旋律表格里**逐字手改**（每个字、每个音高、每个时值都可编辑，自动保存）。

### ③ 演唱

- 「音色名」填你 GPT-SoVITS 控制页里的声音模型名（如 `myvoice_test`）；
- 点 **「🎤 按旋律唱出来」**：逐字合成 → 每个字变调到对应音符的音高 →
  时长对齐 → 按旋律节奏拼成整首歌，完成后自动播放；
- **只合成前 60 秒** 勾选框用于快速试听；**哼鸣试听** 不需要任何模型，秒出，用来核对旋律。

## 三、声音从哪来（GPT-SoVITS）

演唱使用你机器上的「GPT-SoVITS 声音模型」控制页（8550 端口）：

- **原唱声**：用原曲的人声录音在控制页里训练一个音色（1 分钟以上录音即可），选它；
- **换人唱**：导入任何社区音色，选它；
- 工作台的看门狗会顺带守护控制页（8550 掉线自动拉起）。

> 注意：合成在 CPU 上运行，速度受机器当前负载影响大。建议演唱时关掉其他大型 AI 程序；
> 首次合成要加载音色（几分钟），之后每字几秒。加一块 N 卡后可提升数十倍。

## 四、项目结构

```
获取旋律/
├── 启动工作台.bat / 关闭工作台.bat     双击启动（看门狗守护）/ 一键停止
├── setup.bat                          首次安装依赖
├── watchdog.bat + wd_*.ps1            看门狗：服务与 GPT-SoVITS 控制页掉线自动拉起
├── server.py                          服务端（旋律库/文档/校验/演唱/导出）
├── config.json                        音色名、GPT-SoVITS 地址与项目目录等
├── prompts/
│   ├── 旋律生成文档.md                 复制给 DeepSeek 生成旋律的约束文档
│   └── 填词约束模板.md                 填词文档的骨架（工作台自动填充旋律）
├── melodies/                          ★ 旋律库：DeepSeek 生成的旋律 JSON 放这里
├── exports/                           演唱与导出的成品
├── web/                               页面
├── workbench/                         核心代码（旋律校验/文档生成/演唱合成/导出/简谱）
├── test_suite.py                      全功能回归测试（20 项）
├── tmp_test/                          测试产物（最新的）
└── songs/                             （旧版音频提取的遗留数据，不再使用）
```

## 五、常见问题

- **页面打不开**：双击「启动工作台.bat」；工作台有看门狗守护，服务意外退出会自动拉起（端口 17865）。
- **DeepSeek 回复粘进去报校验失败**：错误信息会写明哪句差几个字，把错误原样发给 DeepSeek 让它修正。
- **演唱没声音/失败**：确认 GPT-SoVITS 控制页（8550）开着、音色名拼写正确；看进度面板里的日志。
- **想改端口**：全局搜索 `17865` 替换（server.py、三个 bat、wd_portcheck.ps1、test_suite.py）。
- **测试**：`.venv\Scripts\python test_suite.py`，20 项全过为正常；结果同时写入 `tmp_test/last_regression.json`。
