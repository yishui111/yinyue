# 旋律生成约束文档（复制全文给 DeepSeek 网页对话框使用）

> 使用方法：先把下面【填写区】里等号后面的内容改成你要的，然后把整篇文档（包括填写区）
> 全部复制 → 粘贴到 DeepSeek 对话框发送 → 把它回复的 JSON 保存为 `.json` 文件，
> 放进工作台的 `melodies` 文件夹（或在页面"导入旋律"里粘贴）即可。

---

## 【填写区】（改等号后面的内容）

- 参考歌曲 = 苹果香
- 风格情绪 = 温暖思念的民谣流行
- 段落数量 = 8 句
- 每句长度 = 9 到 12 个音符
- 调性 = C major
- 速度 BPM = 96

---

# 正文（以下内容原样发给 DeepSeek）

你是专业的流行音乐作曲人。请根据下面的要求，**生成一段旋律**，并以**只输出一个 JSON 对象**的方式回复，除 JSON 外不要输出任何解释、不要 markdown 代码块。

## 旋律要求

1. 【参考歌曲】：如果是真实存在的歌曲名，请凭你对这首歌的了解，尽量**还原它的主旋律**（音高走向和节奏都要像）；如果写的是"原创"，请按乐理创作一条全新的、好听的旋律。
2. 【风格情绪】：音符的选择与节奏要符合指定风格。
3. 结构：按要求的句数组织，句内音符连贯，句与句之间有呼吸感；音程以级进为主，偶尔 3~5 度跳进，禁止超过 8 度的大跳。
4. 音高范围：midi 编号 48 到 79（大约 C3 到 G5，男女人声都舒适），同一句内音高起伏自然。
5. 时值：duration 单位是秒，取 0.25 到 2.0；一句之内长短结合，句尾音可以稍长。
6. 必须给出 key（调性）和 bpm（速度），与【填写区】一致。

## 输出 JSON 格式（只能输出这个 JSON，一个字都不能多）

{
  "title": "歌名",
  "key": "调性，如 C major",
  "bpm": 96,
  "lines": [
    {
      "text": "第一句（可写这一句的歌词或情绪说明）",
      "notes": [
        {"midi": 64, "duration": 0.5},
        {"midi": 62, "duration": 0.5}
      ]
    }
  ]
}

## 硬性检查（输出前自己过一遍）

- lines 的数量 = 段落数量；
- 每行 notes 的数量在【每句长度】范围内；
- 每个 note 都有整数 midi（48~79）和小数 duration（0.25~2.0）；
- 整个回复是一个合法 JSON（这一点最重要）。

现在，按【填写区】的要求生成旋律，只输出 JSON。
