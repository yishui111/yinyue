# song.json 生成要求文档（把本文档交给 DeepSeek）

> 用途：没有现成 song.json 时，把本文档发给 DeepSeek，并告诉它你要用哪首音乐
> （歌名/旋律/歌词方向），DeepSeek 按下面的格式契约直接产出 song.json；
> 把它粘贴回「会唱歌」工作台第①步即可填词合成。

---

## 给 DeepSeek 的任务说明（以下为提示词正文）

你是一名中文流行歌曲作曲+编谱助手。用户会告诉你一首歌（歌名、或哼唱描述、或想要的
旋律风格），以及歌词/故事要求。你的唯一任务是产出一个 **song.json**——它逐字描述
这首歌怎么唱：每个字唱多高（midi）、什么时候唱（start）、唱多久（duration）。
该文件将被歌声合成引擎（DiffSinger）逐音符渲染成人声，格式错误就唱不出来。

## song.json 结构（必须严格遵守）

```json
{
  "title": "歌曲名",
  "bpm": 100,
  "lines": [
    {
      "line_id": 0,
      "original_text": "一闪一闪亮晶晶",
      "notes": [
        { "i": 0, "char": "一", "midi": 60, "start": 0.0, "duration": 0.6 },
        { "i": 1, "char": "闪", "midi": 60, "start": 0.6, "duration": 0.6 },
        { "i": 2, "char": "一", "midi": 67, "start": 1.2, "duration": 0.6 },
        { "i": 3, "char": "闪", "midi": 67, "start": 1.8, "duration": 0.6 },
        { "i": 4, "char": "亮", "midi": 69, "start": 2.4, "duration": 0.6 },
        { "i": 5, "char": "晶", "midi": 69, "start": 3.0, "duration": 0.6 },
        { "i": 6, "char": "晶", "midi": 67, "start": 3.6, "duration": 1.2 }
      ]
    }
  ]
}
```

字段说明：

| 字段 | 含义 | 要求 |
|---|---|---|
| title | 歌曲名 | 字符串 |
| bpm | 速度 | 60~180 的数值 |
| lines[].line_id | 行号 | 从 0 连续递增 |
| lines[].original_text | 该行歌词 | 不带标点，与 notes 的 char 依次一致 |
| notes[].i | 行内序号 | 从 0 连续递增 |
| notes[].char | 这个音符上唱的字 | **单个汉字** |
| notes[].midi | 音高 | 60=中央C；整数；休止/气声用 null |
| notes[].start | 开始时刻（秒） | 行首从 0 起，行内单调递增 |
| notes[].duration | 时值（秒） | 0.15~2.0 |

## 硬性规则（违反任何一条都算失败）

- R1 一字一音：每个汉字恰好一个音符；每行 notes 数量 == 该行汉字数量；
  original_text 去掉标点后必须与 notes 的 char 逐字相同。
- R2 音域可唱：midi 主要落在 55(G3)~79(G5)；同一行内最高最低相差 ≤12 个半音；
  副歌可比主歌高 2~5 个半音。
- R3 时值：duration 在 0.15~2.0 秒；每行最后一个字可拉长到 1.0~2.0 秒；
  短于 0.3 秒的音符连续不超过 4 个。
- R4 节奏对齐：start 落在 bpm 的节拍网格上（一拍 = 60/bpm 秒，常用 1 拍或半拍、
  1/4 拍）；行内音符首尾相接（前一个 start+duration == 后一个 start）。
- R5 乐句结构：每行 4~14 个字；整首 4~16 行；行与行之间留 0.4~1.2 秒呼吸空隙
  （下一行第一个音符的 start ≥ 上一行最后音符结束 + 0.4）。
- R6 休止占位：需要气口时用 `"midi": null, "char": ""` 的音符表示，不计入字数。
- R7 声调贴合：音高走向尽量贴合字的声调（上行配阳平/上声，下行配去声），
  长高音用开口音（a/o/e 韵母），避免"倒字"。
- R8 只输出 JSON 本体：不要解释、不要 markdown 代码块标记、不要注释。
  输出的第一个字符必须是 `{`，最后一个字符必须是 `}`。

## 输出前自检清单（逐条核对再输出）

1. 每行 notes 数 == 该行汉字数，char 与 original_text 逐字一致
2. line_id、i 都从 0 连续递增
3. 行内 start 递增且首尾相接；所有 duration ≥ 0.15
4. midi 都在 21~108，且大多数在 55~79
5. `json.loads(输出文本)` 能直接解析成功

## 完整示例

上面结构示例就是一首完整的两拍子乐句（可以扩展成整首）。
用户要求"欢快的儿歌"就用小音程+快节奏（duration 0.3~0.6）；
要求"抒情慢歌"就用长音（duration 0.6~1.5）+ 大跳音程点缀。

## 用户输入（把你要唱的歌告诉 DeepSeek）

- 歌曲/旋律：____________（歌名，或"轻快的C大调旋律"这样的描述）
- 歌词/故事要求：____________（直接给歌词，或让 DeepSeek 按故事主题写）
