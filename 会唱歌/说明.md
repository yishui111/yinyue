# 会唱歌 —— 旋律 + 歌词 → 真的唱出来

`获取旋律` 工作台把旋律保存在 song.json、DeepSeek 按约束把新词填好之后，
**最后一步「由你把它唱出来」就是本目录**：

```
song.json（旋律+逐字对位） ──► ds_builder.py 生成 .ds（注音/音素时长/f0 曲线）
                                │
                                ▼
                openvpi/DiffSinger 本地推理（GPU，v2.5.1 + 官方中文声学模型）
                                │
                                ▼
                       干声 wav（44.1kHz，标准合成女声）
                                │  可选 --role（本文件夹自带的 换声引擎\）
                                ▼
                    二次元角色音色 wav（芙宁娜/纳西妲/…）
```

## 一、用了哪些开源项目

| 环节 | 项目 | 说明 |
|---|---|---|
| 唱声合成 | [openvpi/DiffSinger](https://github.com/openvpi/DiffSinger) v2.5.1（Apache-2.0，`diffsinger\`） | 学术界/社区主流开源 SVS，逐音符控制音高，`.ds` 文件驱动 |
| 中文声学模型 | openvpi 官方发布 [`0211_opencpop_ds1000_keyshift`](https://github.com/openvpi/DiffSinger/releases/tag/v1.6.0)（735MB） | Opencpop + DS-1000 中文歌唱数据训练，44.1kHz，**仅限非商业用途** |
| 声码器 | openvpi [NSF-HiFiGAN 44.1k](https://github.com/openvpi/vocoders/releases/tag/nsf-hifigan-44.1k-hop512-128bin-2024.02)（50MB） | mel → 波形 |
| 注音 | [pypinyin](https://github.com/mozillazg/python-pinyin) + 模型自带 `opencpop-extension.txt` 音素字典 | 汉字 → 无调拼音 → 声母/韵母音素 |
| 换二次元音色 | [svc-develop-team/so-vits-svc](https://github.com/svc-develop-team/so-vits-svc) 4.1 推理代码 + `换声引擎\models\` 角色（已收进本文件夹） | 干声 → 角色音色，本地推理 |

> 为什么不是 OpenUtau？OpenUtau 只有图形界面、没有命令行渲染，没法做成"一键唱出来"的服务。
> DiffSinger 官方 Python 推理 + 我们自己生成 `.ds`，整条链路全自动。

## 三、快速上手

```
安装环境.bat     首次一次：硬链接克隆 runtime + 自检依赖（缺什么才联网补装；模型仍需按上面下载）
启动.bat         开工作台 → 浏览器打开 http://127.0.0.1:8102 操作
停止.bat         按端口结束服务
运行测试.bat     小星星旋律 + 示例新词 → 输出\测试_小星星.wav（约 1 分钟）
```

**工作台页面（http://127.0.0.1:8102）怎么用：**

0. 没有 song.json？点页面上的「⬇ 下载《JSON 生成要求文档》」，把文档发给 DeepSeek
   并告诉它你要用哪首音乐（歌名/旋律/歌词要求），DeepSeek 按文档里的格式契约直接
   产出 song.json，回到页面粘贴进第①步即可。文档本体：`DeepSeek生成songjson要求文档.md`。
1. 载入示例或上传/粘贴 `song.json` → 解析出每行音符
2. 逐行填歌词（每行字数必须等于音符数，页面实时红绿提示；也可「整段粘贴新词」）
3. 选二次元音色（换声引擎\models\ 里的角色）、升降调、音色男女 → 点「🎤 唱出来」→ 页面直接试听/下载

命令行直接合成：

```bat
runtime\py312\python.exe sing.py song.json [填词.json] [-o 输出\xxx.wav] [--role furina] [--key -2]
```

- `song.json`：`获取旋律` 工作台的旋律结构，或按 DeepSeek生成songjson要求文档.md 让 DeepSeek 生成
- `填词.json`：DeepSeek 的填词结果（lines[].line_id/chars 或 line_id/text），省略则唱 song 里的原字
- `--role`：角色名（`换声引擎\models\` 里的 json 前缀，如 furina/nahida41），填了会同时产出干声和角色音色两版
- `--key`：整体升降半音（贴合演唱者音域）；`--gender`：-1~1 音色偏男/偏女

## 四、HTTP 接口（8102）

```
GET  /                → 工作台页面（static\index.html）
GET  /static/<文件>    → 页面静态资源
GET  /health          → {"status":"ok","model":...,"model_ready":...,"svc_roles":[...]}
GET  /api/demo        → {"song": 小星星 song.json, "lyrics": 示例填词}
GET  /api/spec        → 下载《DeepSeek 生成 song.json 要求文档》
POST /sing            → 请求体 JSON：
       {"song": {...song.json 原样...},
        "lyrics": {"lines":[{"line_id":0,"text":"弯弯月亮像小船"}]},   ← text 或 chars 均可；
                   整项省略则唱 song 里的原字
        "role": "furina",      ← 可选，换声引擎\models\ 里的角色
        "key": 0, "gender": 0, "seed": -1}
       ← audio/wav（同步推理；警告在响应头 X-Sing-Warnings）
```

curl 示例：

```bash
# 下载要求文档
curl http://127.0.0.1:8102/api/spec -o DeepSeek生成songjson要求文档.md
# 合成（带芙宁娜换声）
curl -X POST --data @req.json http://127.0.0.1:8102/sing -o 唱歌.wav
```

错误（如某行字数 ≠ 音符数）返回 JSON：`{"error": "...", "warnings": [...]}`。

## 五、`.ds` 是怎么造出来的（ds_builder.py 的规则）

- 每行歌词一个 DS 段，`offset` 定位到该行首音符前 0.12s
- 注音：pypinyin 无调拼音查字典；拼音 → 1~2 个音素（声母+韵母，如 `wan → w an`），
  特殊读音字典里都有（zhi→`zh ir`、zi→`z i0`、ju→`j v`）
- 音素时长：声母取音符时值 28%（夹在 0.05~0.24s），韵母吃剩下的
- f0 曲线：10ms 一帧；音符内恒定在 MIDI 音高，相邻音间 40ms 线性滑音，休止为 0
- 休止：行内空隙 ≥0.1s 记 SP，≥0.5s 先 AP（换气）后 SP；`midi:null` 的音符当休止
- 字数 ≠ 音符数会直接报错（DeepSeek 约束文档 R1 本来就要求相等）

## 九、合成快慢

- 常驻渲染器（ds_render.py）：模型进程内只加载一次——
  服务启动后**第一次**合成要付 import torch + 800MB 模型加载（40s~3min，取决于机器负载），
  **之后每次合成只要推理本身的时间（实测约 8~30 秒）**。
- 角色换声同理：每个角色模型首次使用加载一次（约 20~100s，看负载），同角色之后很快。
- 机器被其他训练/下载任务占满磁盘或显卡时，以上时间会成倍变长；合成报错会自动重试一次。
