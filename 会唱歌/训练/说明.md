# 训练 · 自己的二次元唱歌音色

把一个角色的干净人声素材训练成 **so-vits-svc 4.1 唱歌换声模型**，训完自动放进
`..\换声引擎\models\`，「会唱歌」工作台的换声下拉框里立即可选。

## 快速开始（页面）

1. 双击 `启动.bat`（或根目录 `全部启动.bat`）→ 打开 http://127.0.0.1:8103
2. 把该角色的干净人声（无伴奏/混响，3~10 分钟以上）放进一个文件夹
3. 页面填 **角色名** + **素材文件夹路径** → 点「🚀 开始训练」
4. 训练是小时级长任务：可中断（自动断点续训）；中途想先用就点「📦 导出当前进度」
5. 去 http://127.0.0.1:8102 的唱歌工作台，换声角色里选它，唱歌！

命令行等价：`..\runtime\py312\python.exe 训练流水线.py 全流程 <角色名> <素材目录>`

## 它是怎么训练的（流水线五步）

1. **重采样**：素材 → 44.1kHz 单声道（`resample.py`，librosa 实现，不需要 ffmpeg）
2. **文件列表/配置**：`preprocess_flist_config.py` 生成 filelists + `configs/config.json`
   （编码器固定 **vec768l12-onnx**，与换声引擎推理完全一致，无需 fairseq）
3. **底模微调**：官方 vec768l12 预训练底模（`底模\G_0.pth/D_0.pth`，已自动下载）
   复制为训练起始 checkpoint；中断重跑自动断点续训
4. **特征提取**：`preprocess_hubert_f0.py`（content + f0，rmvpe 提取音高）
5. **训练**：`train.py -c configs/config.json -m 44k`，产出在 `so-vits-svc\logs\44k\`

导出逻辑：取 `logs\44k\` 里最新的 `G_*.pth` + 训练配置 → 复制为
`换声引擎\models\<角色名>_G.pth` + `<角色名>.json`。

## 环境要求与注意

- 环境复用会唱歌的 `..\runtime\py312`；依赖 rich/loguru 已装好，**不需要 fairseq**
  （本副本对 `preprocess_flist_config.py` / `preprocess_hubert_f0.py` 打了两个小补丁，
  让训练走 onnx 编码器并支持 `-d cpu`，与推理行为一致）
- 训练时**不要同时**进行换声/合成等大显存任务；机器被其他训练/下载占满时特征提取
  会自动从 GPU 多进程回退到 CPU 单进程
- `logs\44k` 一次只放一个角色的训练进度：换角色训练请加 `--restart`（页面重新开始
  同理），否则会带着上一个角色的断点
- 底模来源：hf-mirror `Sucial/so-vits-svc4.1-pretrain_model`（vec768l12），已下载在 `底模\`

## 模型格式（会唱歌直接可用）

`换声引擎\models\<角色名>.json` + `<角色名>_G.pth`（可选：`<角色名>_kmeans.pt` 或
`<角色名>_feature_and_index.pkl`）。符合这个命名的模型放进来就能被识别。
